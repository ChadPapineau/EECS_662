# Project 3 - Functions and Elaboration

Mini Project 3 - Static Scoping and Elaboration </br>
EECS 662 - Programming Languages </br>

The objective of this mini-project is to add dynamically scoped and statistically scoped strict functions to BAE
and introduce elaboration ot the interpretation process.</br>

In order to do this, define an interpreter that adds functions and a conditional construct to BAE while removing the bind
expression. Then define an interpreter that uses elaboration to define interpretation of bind in terms of function application.
